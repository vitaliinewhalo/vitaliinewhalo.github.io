# Vitalii — Full-Stack Developer Portfolio

Personal engineering portfolio website hosted on GitHub Pages:
**[https://vitaliinewhalo.github.io/](https://vitaliinewhalo.github.io/)**

## Tech Stack
- **Architecture**: Semantic HTML5, Modern CSS3 with CSS Custom Properties, Vanilla JavaScript (ESNext)
- **Design**: Clean Tech / Minimalist aesthetic with full Dark & Light mode toggle
- **Typography**: Plus Jakarta Sans & JetBrains Mono
- **Deployment**: GitHub Pages (Zero build step, instant deployment)

## Key Features
- **Interactive Project Filtering**: Filter by Full-Stack, Frontend & UI, and Backend & Bots
- **Interactive Developer Console**: Syntax-highlighted code tabs (`profile.ts`, `stack.json`, `workflow.sh`)
- **Theme Switcher**: Smooth transitions with automatic system preference detection & `localStorage` persistence
- **Quick Actions**: One-click clipboard copy for email and direct links to GitHub & Telegram
- **Accessibility & Performance**: 100/100 performance score, responsive on all device viewports
